# Бюджетное окружение процесса закупок. Просто о сложном

Лендинг практического курса АО «Сбербанк-АСТ» (Электронный университет).

Три занятия — путь бюджетных денег в закупке: **бюджетный процесс и казначейское обслуживание → планирование закупок и блокирующий контроль → исполнение контракта и казначейский платёж**.

Стоимость: **9 000 ₽** за весь курс, **3 000 ₽** за отдельное занятие.

## Файлы

- `index.html` — самодостаточный сайт (GitHub Pages), внешних зависимостей нет (кроме шрифта Manrope с Google Fonts).
- `getcourse.html` — версия для ГетКурса: независимые блоки с маркерами разреза «✂», без глобальной обёртки; стили изолированы префиксом `bpz-`; UTF-8 с BOM. Нативный блок «Форма» ГетКурса ставится после блока «Запись».

## Запуск локально

```bash
python -m http.server 8100
# http://localhost:8100
```

## Структура

Одностраничный сайт: hero · оффер · для кого · зачем сейчас · результаты · формат · программа (3 занятия) · стоимость · спикер · преимущества · форма записи.

Интерактив: аккордеон программы, валидация формы, мобильное меню, анимации появления.
