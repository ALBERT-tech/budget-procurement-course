# Бюджет и закупки без разрывов

Лендинг практического курса АО «Сбербанк-АСТ» (Электронный университет) — «от планирования до контроля».

Единая логика: **бюджет и ЛБО → планирование закупок → исполнение контракта → финансовый контроль**.

## Запуск

Один самодостаточный файл — откройте `index.html` в браузере. Внешних зависимостей нет (кроме шрифта Manrope с Google Fonts).

Локально:

```bash
python -m http.server 8100
# http://localhost:8100
```
